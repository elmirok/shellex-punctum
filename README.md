# Punctum

Punctum is a host text editor app for files inside the encrypted vault.

Open it with `punctum <path>` or `edit <path>` from Shell. It is useful for quick notes, config files, markdown drafts and small project files.

## Quick commands

```txt
punctum
punctum /home/Documents/notes.md
edit /system/w3/config.json
```

## Keys

```txt
Ctrl+O  save the current file
Ctrl+R  open the path in the path field
Ctrl+X  close Punctum
```

## Shellex package

- App id: `system.punctum.local`
- Version: `1.0.1`
- Runtime: `host`
- Type: `system-app`
